# Gerenciador de Tarefas em Python

Aplicação desenvolvida em Python como parte dos meus estudos de programação e Engenharia da Computação.

## Sobre o projeto

O Gerenciador de Tarefas é uma aplicação executada no terminal que permite cadastrar, visualizar, concluir e excluir tarefas.

O programa utiliza arquivos JSON para armazenar as informações, permitindo recuperar as tarefas mesmo após o encerramento da aplicação.

## Funcionalidades

- Adicionar novas tarefas.
- Listar tarefas cadastradas.
- Identificar tarefas concluídas e pendentes.
- Marcar tarefas como concluídas.
- Impedir a conclusão duplicada de tarefas.
- Excluir tarefas.
- Salvar e carregar tarefas utilizando JSON.
- Tratar entradas numéricas inválidas.

## Tecnologias utilizadas

- Python
- Biblioteca JSON
- PyCharm
- Git e GitHub

## Como executar

1. Instale o Python 3.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute o arquivo principal:

```bash
python main.py
```

**Observação:** se o arquivo Python tiver outro nome, substitua `main.py` pelo nome correspondente.

## Armazenamento dos dados

As tarefas são armazenadas localmente no arquivo `tarefas.json`, que não é enviado ao GitHub.

Praticar conceitos de programação, como funções, estruturas condicionais, laços de repetição, listas, dicionários, tratamento de exceções e persistência de dados.
